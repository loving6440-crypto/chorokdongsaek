# Font assets

Run `PACK_FONTS.cmd` in project root after putting originals in the project folder (or Downloads). This places five font files here and creates a distributable ZIP.

Expected paths:
- PF-Stardust-Regular.ttf
- PF-Stardust-Bold.ttf
- PF-Stardust-ExtraBold.ttf
- Silver.ttf
- Ramche.ttf

The uploaded source fonts themselves are not distributed in this source ZIP.
