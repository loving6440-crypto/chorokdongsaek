# 글꼴 설치 안내

업로드한 글꼴 파일 자체는 이 배포 ZIP에 재배포하지 않습니다. 소유한 원본을 아래 경로에 복사한 뒤 빌드하세요.

- `PF스타더스트 3.0.ttf` → `public/fonts/PF-Stardust-Regular.ttf`
- `PF스타더스트 3.0 Bold.ttf` → `public/fonts/PF-Stardust-Bold.ttf`
- `PF스타더스트 3.0 ExtraBold.ttf` → `public/fonts/PF-Stardust-ExtraBold.ttf`
- `Silver.ttf` → `public/fonts/Silver.ttf`
- `Ramche.zip` 내부의 `Ramche.ttf` → `public/fonts/Ramche.ttf`

NEO둥근모는 웹 CDN, 갈무리9는 quiple/galmuri 릴리스 v2.40.4의 CDN을 통해 로딩합니다.

글꼴 파일을 추가하지 않으면 해당 선택지에서 기본 폰트로 대체 표시됩니다.
