- 전체 `src`, `server` JS/JSX 파싱: **문법 오류 0개**
- `node server/index.js` 서버 구동 및 `/api/health` HTTP 200 확인
- ZIP 자체 무결성 검사

## 실서버 배포 전 반드시 확인

1. **테스트 서버에서 먼저 배포**하고 기존 캐릭터의 체력, 영력, 수련/대기 완료, 계정 전환, 저장 복원을 확인하세요.
2. 브라우저 개발자 도구 Network에서 `/api/account/save` 요청이 가만히 있는 동안 불필요하게 반복되지 않는지 확인하세요. 실제 DB egress 감소량은 운영 환경에서 계측해야 합니다.
3. 활성 활동이 아닌 동안 숫자 게이지 표시가 최대 5초 단위로 갱신될 수 있습니다. 회복량 자체는 실제 경과 시간으로 계산됩니다.
4. v76 원본의 `package-lock.json`은 `package.json`과 일부 종속성 기록이 일치하지 않습니다. 이 환경에서는 npm 레지스트리 DNS가 막혀 `npm ci`/`npm run build`까지 완료하지 못했습니다. 연결된 환경에서 `npm install` 후 `npm run build`를 실행하고 새 잠금파일을 함께 커밋하세요. 해당 문제로 Dockerfile은 `npm install`을 사용하도록 변경했습니다.
5. 실제 브라우저 프로파일러 및 여러 명 동시 접속 부하 테스트는 하지 못했습니다. 서버 동기화/DB 경합을 완전히 해결했다고 주장하지 않습니다.
