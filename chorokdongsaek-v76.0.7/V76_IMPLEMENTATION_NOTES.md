# 초록동색 v76 — 통합 업데이트

기준: v74 전투 UI 수정본. 프로젝트 버전: `76.0.0`.

## 반영 사항

- 전투 UI/영능력 설명: 행동 순서, 간파 기반 행동 정보, 영능력 상세 분리 표기, 능력 발동 팝업 유지.
- 규칙: 인내의 확률형 피해 감소, 석장 비용 20% 감소, 다인 전투 턴 비소모 아이템 타인 턴 사용.
- 무구 강화: +15단계, 단계별 연마석/보조 재료/영력 소비, 강화 확인, 무명천으로 특수 강화 제거 및 사용 화투패 회수.
- 소지품: 수량 선택 후 버리기, 신규 아이템 및 전용 벡터 아이콘.
- UI: 기숙사 메뉴 통합 및 꾸미기 자리, 안내서 유도, 안내 버튼 간소화, 화투패 그림을 화투 미니게임 표현으로 재사용, 스킨 상세 설명.
- 소통: 친구 목록/추가/삭제/차단/해제, 접속 표시, 쪽지/선물/파티 초대 연결, 차단 유저 채팅 숨김, 시스템 알림 기록.
- 급식실: 최근 일주일 신문 열람, 날짜별 교내 기사.
- 보드게임/수업 미니게임: 가능한 한 게임 중앙 영역에 표시하고 우측 채팅 영역이 가려지지 않도록 조정.

## 검증

- `node --test tests/v76.test.mjs`: 6개 테스트 통과 (강화 비용/상한, 특수 강화 회수, 버리기, 석장 할인, 인내, 아이템 ID).
- 프로젝트 `src/`, `server/` JS/JSX 문법 검사 통과.
- `server/index.js` 로 서버 구동 및 `/api/newspaper` 실제 응답 확인.
- 상대 경로 import 경로 모두 확인.
- `npm ci`가 실행 환경 네트워크/제한시간으로 완료되지 않아 **Vite 프로덕션 빌드 및 실제 브라우저 전 과정 검증은 진행되지 못함**.

## 배포 전 주의

- 로컬 환경에서 `npm ci && npm run build` 후 Render의 테스트 서버에 배포하여 다인 전투, 계정 간 선물, 서버 재연결과 게임 화면 전환을 실제 계정 두 개 이상으로 테스트하세요.
- 친구 관계는 서버 저장되지만 아이템 선물과 아이템 버리기 등 기존 캐릭터 저장/동기화 흐름은 **완전한 데이터베이스 원자 트랜잭션으로 보장된 것으로 간주하면 안 됩니다**.
- 신규 이용자 안내서 노출 여부는 계정값을 키로 하는 브라우저 localStorage 기반이며 서버 간 기기 동기화는 지원하지 않습니다.
- 기사 데이터는 날짜별 생성된 교내 기사 및 서버에 있는 기존 신문을 함께 표시합니다. 실시간 기사 편집 CMS는 포함하지 않았습니다.
