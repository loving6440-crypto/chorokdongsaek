# 秘靈 (비령) · 16bit 웹 메인 / C.01 시스템 이식 준비판

## 실행
- `index.html`을 브라우저에서 열면 메인 디자인/사방 선택/기록/글꼴 토글이 실행됩니다. 별도의 빌드 도구가 필요 없습니다.
- 폰트 원본은 `fonts/README.md` 참조.

## 이번에 적용한 항목
1. 이름: 사이트 타이틀/상단 로고/메인 헤더/메뉴의 `비령산 임시학당` → `秘靈(비령)` 또는 `비령`. 비령산은 지명으로 유지.
2. 파란 무당칼 라인 아이콘: `assets/favicon.svg`와 `assets/favicon.png`. 상단 로고에도 사용.
3. 글꼴: 초록동색 `useFont.js`의 7개 id/명칭/순서와 같은 폰트 선택 메뉴; 즉시 반영, localStorage 유지.
4. 초록동색 C.01 원본 전투·개척·육조 시스템: `systems/chorokdongsaek-C01/src/game` 내부 원본 게임 데이터와 계산 엔진 전체, 관련 UI/서버 검증 소스 및 일부 테스트가 **내용 변경 없이** 보존되어 있습니다.
5. `systems/core.mjs`는 앞으로 실행 UI에 연결할 때 쓸 엔진 진입점입니다.

## 구현 상태 / 주의사항
- **아직 메인 UI와 전투·개척 게임 플레이를 연결하지 않았습니다.** 요청대로 데이터와 계산 로직만 먼저 넣은 상태입니다. 실사용 전투/개척을 지금 실행할 수 있다고 주장하지 않습니다.
- 원본 React UI 소스는 **참고 보존**되어 있으며, 정적 HTML에 마운트되지 않았습니다. `server/index.js` 또한 백업용으로 포함돼 있고 가동되지 않습니다.
- 온라인 다인 전투, 서버 검증 개척, 장부/경제, 사용자 저장은 초록동색 서버와 데이터베이스 기반입니다. 현재 비령에는 관련 **코드/규칙만** 보존했으며 실제 라우팅, DB 스키마·마이그레이션·인증 연결, 서버 배포는 아직 아닙니다.
- 육조: 안목(insight), 호전(aggression), 인내(endurance), 절제(control), 신속(agility), 이해(comprehension). 고유 스탯 키와 수치/전투 규칙을 변경하지 않았습니다.
- 모듈의 정확한 적용 동작은 원본 의존성 및 백엔드가 함께 구성되는 후속 단계에서 통합 검증해야 합니다.
- 정적 브라우저 표시 기능만 검증 대상입니다. `systems` 디렉터리의 모듈은 정상 사용을 위해 별도 앱 빌드 및 서버 연동이 필요합니다.

## 폴더
- `index.html` 메인
- `styles.css` UI
- `app.js` 상호작용/글꼴 선택
- `assets/` 일러스트 및 파비콘
- `fonts/` 원본 서체 투입 위치
- `systems/core.mjs` 육조/전투/개척 엔진 모듈 경유
- `systems/chorokdongsaek-C01/` 원본 스냅샷, 검증 보존용

초록동색 C.01 원본을 덮어쓰지 않고 비령에 별도 복사하여 사용합니다.
