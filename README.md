# 草綠同色 (초록동색)

방치형 수련 + 미니게임 학원물 웹 게임. (구 '국립 창록고등학교')

```bash
npm install
npm run build    # 배포 빌드 (dist/)
npm start        # 서버 실행: 게임 + 채팅 · 파티 · 랭킹  → http://localhost:8787
```

개발 중에는 터미널 두 개로 `npm run server` 와 `npm run dev` 를 함께 띄운다. (vite 가 `/api` 를 8787 로 넘겨 준다.)
서버 없이 `npm run dev` 만 켜도 게임은 돌아가지만 채팅 · 랭킹은 '서버에 연결되지 않음' 으로 표시된다.

환경 변수: `PORT`(기본 8787), `CHOROK_DATA`(랭킹 저장 파일, 기본 `server/data.json`), `CHOROK_DIST`(정적 파일 폴더).

### 서버 (`server/index.js`, 의존성 없음)
- 채팅: 연락(RP, 공개) · 담화(일반, 공개) · 일행(파티원끼리만). 최근 100줄을 메모리에 보관한다.
- 파티: 접속자 목록에서 초대 → 상대에게 "일행으로 참여하시겠습니까?" (네/아니오).
- 랭킹: 과목별 각자의 최고 기록만 남기며 `data.json` 에 저장된다.
- 계정과 저장 데이터는 지금까지처럼 각자의 브라우저(localStorage)에 있다. 서버는 클라이언트가 보낸 아이디 · 점수를 그대로 믿는다.

## 구성
- `src/components/Intro.jsx`, `FitLines.jsx` — 첫 캐릭터 생성 전 인트로. 문장 하나는 항상 한 줄이며 화면 폭에 맞춰 글자 크기가 자동 조절된다. 문단 내용은 `src/game/intro.js`
- `src/components/CharacterCreation.jsx` — 신입생 등록 (단색 프로필은 #코드 입력, 글자 없이 색만 표시)
- `src/game/sfx.js` — 효과음. 외부 음원 파일 없이 Web Audio 로 합성한다. 전체 볼륨은 `MASTER` 한 곳에서 조절. 버튼에 `data-sfx="none"` 을 달면 공통 클릭음이 꺼지고, `data-sfx="이름"` 으로 다른 소리를 줄 수 있다
- `src/components/GameModal.jsx` — 과목 → 미니게임 연결표(`MINIGAMES`). 새 게임은 여기에 등록
- `src/components/minigames/` — 미니게임 화면
- `src/game/minigames/` — 규칙·데이터 (UI 없이 테스트 가능)

## 수정하면서 쓰기 (v21)
- `npm run live` 한 줄이면 서버 + 자동 재빌드가 같이 돈다. 고치고 브라우저 새로고침만 하면 반영된다. (서버 코드를 고치면 서버도 자동 재시작)
- 데이터가 날아가는 이유와 방지:
  - 계정·저장은 브라우저 localStorage 에 있고 **주소(포트)별로 따로** 저장된다. 항상 같은 주소(`http://localhost:8787`)로만 접속할 것. (`npm run dev` 는 5173 이라 다른 저장소다)
  - 랭킹은 `server/data.json`. 새 버전을 풀 때 **폴더를 새로 만들지 말고 기존 폴더에 덮어 풀기** (`tar xzf 새파일 --strip-components=1`). `node_modules`와 `data.json`은 안 건드린다.

## Render 에 올리기 (무료 플랜)
1. 이 폴더를 GitHub 저장소로 올린다. (`.gitignore` 로 node_modules · dist · data.json 은 제외)
2. Render > New > Blueprint 로 저장소를 연결하면 `render.yaml` 대로 서비스가 만들어진다.
3. 이후엔 GitHub 에 push 할 때마다 자동 재배포된다. 주소(`https://<이름>.onrender.com`)는 고정이다.
- 무료 플랜은 디스크가 없어서 재배포 · 재시작(15분 접속이 없으면 잠듦) 때 랭킹과 채팅 기록이 초기화된다.
- 계정 · 저장은 각자 브라우저에 있으므로 주소만 같으면 재배포와 무관하게 남는다.
- 랭킹을 남기고 싶어지면 `plan: starter` 와 `disk:`(mountPath /var/data, `CHOROK_DATA=/var/data/data.json`)를 추가한다.

- 영력 자연 회복은 절제로 결정: 절제 10마다 0.1을 채우는 시간이 5초씩 단축(60초→…→30초, 최대 5분에 1). 신속은 더 이상 영력 속도에 관여하지 않음.
- 체력 자연 회복 = 영력 속도의 2배(의지력은 자연 회복 없음). 수련 보상 = 자연 회복의 2배(소수점 내림, 시작 시점에 확정).
- 학년: 생성 화면에 학년 선택(자동/1~3학년). 자동이면 17·18·19세 → 1·2·3학년.
- 프로필 수정: 프로필 마름모 오른쪽 위 연필 버튼 → 사진·이름·나이·학년.
- 선물: 채팅 접속자 목록의 [선물]. 아이템만 합쳐 최대 5개, 돈은 서버가 거절. 상대가 접속 중이어야 함. (`POST /api/gift`)
- 양호실: [누워서 쉬기](체력 1분에 1) / [선생님과 상담하기](의지력 1분에 1), 1분 단위 시간 설정, 나갈 때 확인.
